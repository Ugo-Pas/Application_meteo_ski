# ☃️ Meteo_Ski

Application mobile pour skieurs permettant de suivre les conditions météorologiques, les risques d'avalanche et les prévisions d'enneigement pour vos stations de ski préférées.

## 📱 Description

Meteo_Ski est une application mobile développée avec React Native et Expo qui fournit aux skieurs des informations essentielles pour planifier leurs sorties en toute sécurité :

- 🌨️ Prévisions d'enneigement
- ⚠️ Alertes risques d'avalanche
- 🌡️ Conditions météorologiques en temps réel
- 📍 Suivi de vos stations favorites

## 🚀 Technologies

- **React Native** 0.81.5 - Framework mobile cross-platform
- **Expo** ~54.0.31 - Plateforme de développement React Native
- **TypeScript** ~5.9.2 - Typage statique
- **Expo Router** ~6.0.21 - Navigation basée sur le système de fichiers
- **React Navigation** - Navigation bottom tabs

## 📋 Prérequis

- Node.js (version LTS recommandée)
- npm ou yarn
- Expo Go sur votre appareil mobile (pour tester) ou un émulateur iOS/Android

## 🔧 Installation

1. Clonez le repository :
```bash
git clone https://github.com/Ugo-Pas/Application_meteo_ski.git
cd Application_meteo_ski/Meteo_Ski
```

2. Installez les dépendances :
```bash
npm install
```

## 🎮 Lancement de l'application

### Démarrage du serveur de développement
```bash
npm start
```

### Lancer sur Android
```bash
npm run android
```

### Lancer sur iOS
```bash
npm run ios
```

### Lancer sur le web
```bash
npm run web
```

### Réinitialiser le projet
```bash
npm run reset-project
```
